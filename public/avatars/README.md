# Avatares de Andresito

Subí aquí los recortes individuales de cada expresión. No subas las plantillas completas.

## Carpetas y nombres

- graduacion/
- navidad/
- verano/
- normal/

En cada carpeta, los archivos deben llamarse exactamente:

- idle.jpg — esperando
- thinking.jpg — pensando
- processing.jpg — procesando
- answering.jpg — respondiendo
- error.jpg — error
- offline.jpg — sin conexión

Preferentemente PNG con fondo transparente. Mantené el mismo tamaño y encuadre en todos los recortes de una temporada.

No cambies los nombres: el widget los utilizará para seleccionar la expresión según la temporada y el estado de Andresito.
